# ecommerce-website (LUXE)

A front-end e-commerce demo called LUXE: shop, product detail, cart drawer, multi-step checkout, account area with order history, plus Home, About and Contact pages. Data is local; there is no backend or payment processing.

Live: https://ecommerce-website-gray-gamma.vercel.app

## Stack

React 18, React Router v6, Vite, Tailwind CSS 3, Framer Motion, Lucide React.

## Run locally

```bash
npm install
npm run dev
npm run build
```
